# Support

## Questions and bug reports

Use a GitHub issue for reproducible bugs, documentation corrections, conversion
questions, and feature proposals. Include a minimal original rule whenever
possible. Remove addresses, internal hostnames, account identifiers, proprietary
signatures, and other sensitive details before posting.

## Security reports

Use the private process in [SECURITY.md](SECURITY.md). Do not submit a security
vulnerability through a regular issue.

## Deployment support

This project does not provide managed IDS or IPS operations. Operators remain
responsible for target-engine configuration, rule licensing, change control,
testing, and production deployment decisions.
